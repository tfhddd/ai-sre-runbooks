# Skills 总索引

holmesgpt 通过 `skillRepos` 加载本仓 `skills/` 目录。结构：`skills/<layer>/<skill>/SKILL.md`。

| 技术层 | 说明 | 索引 |
|---|---|---|
| [infra](infra/INDEX.md) | 基础设施：K8s / 节点 / 网络 / 存储 / 容器运行时 | infra/INDEX.md |
| [middleware](middleware/INDEX.md) | 中间件：Redis / MySQL / Kafka / ES / RabbitMQ | middleware/INDEX.md |
| [app](app/INDEX.md) | 业务应用微服务 | app/INDEX.md |
| [access](access/INDEX.md) | 接入层：网关 / LB / Ingress / CDN / DNS | access/INDEX.md |

新增经验前必读根目录 `../CLAUDE.md`。归档模板见 `../templates/SKILL.template.md`。
